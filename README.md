# TopTrainer is verhuisd

TopTraining heet nu **TopTrainer** en staat op https://app.toptrainerapp.com/.

Deze repository bevat alleen de doorstuurpagina voor het oude adres https://woutvb073.github.io/trainersapp/:
oude links (ook korte deellinks `#/d/…`) gaan naar het nieuwe adres, en wie de oude app op zijn telefoon heeft,
krijgt uitleg om de nieuwe te installeren. De gegevens van het toestel gaan versleuteld mee.
